Full Stack Blog Platform✍️
Full Stack Blog Platform is a modern web application developed using the MERN Stack (MongoDB, Express.js, React.js, and Node.js) that enables users to create, manage, and read blog posts through an interactive and responsive interface.

Features
1. User Authentication 
Secure login and registration using JWT authentication. 
2. Blog Management 
Users can create, edit, delete, and publish blogs using CRUD operations. 
3. AI-Assisted Blog Generation 
Google Gemini API helps users generate blog content through AI prompts. 
4. Rich Text Editor 
Supports formatted blog writing with headings, lists, and styled text. 
5. Image Upload and Optimization 
ImageKit API is used for image upload, storage, and optimization. 
6. Responsive User Interface 
Built with React.js and Tailwind CSS for mobile and desktop support. 
7. REST API Development 
Backend APIs developed using Node.js and Express.js. 
8. Database Management 
MongoDB and Mongoose used for storing and managing application data. 
9. Category and Search Functionality 
Blogs are organized by categories with search support.
